# 三资云图图斑重叠核查（油猴脚本）

在三资数字云图平台页面内运行的 Tampermonkey 用户脚本，用于核查土地资产图斑之间的空间重叠，导出 Excel 明细。**只读核查，不修改平台数据。**

## 版本

| 目录 | 版本 | 说明 |
|---|---|---|
| 根目录 | v1.1.0（当前，通用版） | 基于 v1.0.4 升级：组织名单从平台动态读取，不再硬编码；支持任意街道（账号权限范围内）；经营性/非经营性资产只对房屋建筑物读取图斑详情 |
| `archive/v1.0.4/` | v1.0.4 | 惜福镇专用版：硬编码 31 个组织代码 |

## 核查逻辑

- 读取选定范围内每个组织的资源性（Z）、经营性（J）、非经营性（F）资产列表
- 资源性资产全部读取图斑详情；J/F 只对房屋建筑物（assetClass=02、assetType=01）读取详情
- 重叠口径：交集面积 ÷ min(两图斑面积)，严格大于阈值（默认 20%）纳入；只接触边界不算重叠
- 三类有效图斑放在一起计算，包含跨组织、跨类别及同类别重叠
- 失败项明确列入「异常待核查」，不会被当作无图斑或无重叠

## 导出

重叠明细（12 列：序号、权属单位/资产名称/资产编号/图斑面积 A 与 B、交集面积、重叠比例、备注）+ 组织汇总 + 处理说明；Excel 依赖无法加载时退回 CSV/TXT。

## 安装

1. 安装 Tampermonkey，在油猴中新建脚本，把 `三资云图重叠核查_通用版_v1.1.0.user.js` 内容全选替换进去，Ctrl+S 保存。
2. 只启用本版本，停用旧版脚本；刷新平台页面。
3. 在平台正常登录即可，**不需要在脚本中填写 token 或 Cookie**——脚本运行时从同源 Cookie 读取登录态。

## 使用

1. 点击「读取组织」（惜福镇默认 D370214008），成功后显示组织数量，再点击「开始核查」。
2. 其他街道：展开「从账号组织树选择其他街道」，加载根节点后选择目标街道设为核查范围，再读取组织并核查。只有账号有权读取的范围可用。
3. 详细说明见 `使用说明.txt`。
